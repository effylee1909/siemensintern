上傳文件

上傳即保存至此 Demo 的後端；不會傳至 GitHub 或外部辨識服務。

每份最多 100 MB、150 頁 PDF；一次最多 20 份。初版不支援舊 .doc。翻譯請先選擇所屬公文，避免誤配。新增時每個檔案各建立一筆紀錄。

分類設定

名稱比對協助辨識收發文與往來對象。不會自動改寫已存文件；可在文件內重新辨識。
